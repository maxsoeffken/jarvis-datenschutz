2. Zweck der Anwendung

JARVIS eBay Bot ist eine Anwendung zur Unterstützung bei der Verwaltung und Erstellung von eBay-Angeboten.

3. Verarbeitung personenbezogener Daten

Bei der Nutzung können eBay-Kontodaten, Zugangstoken, Angebotsdaten und gegebenenfalls Bestellinformationen verarbeitet werden. Welche Daten tatsächlich verarbeitet werden, hängt von den aktivierten Funktionen ab.

4. Verbindung mit eBay

Die Anwendung kann über die offizielle eBay-API auf Daten zugreifen, wenn Nutzer die entsprechenden Berechtigungen erteilen. Berechtigungen können über das eBay-Konto widerrufen werden.
